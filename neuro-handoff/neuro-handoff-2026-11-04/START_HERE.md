# НЕЙРО — комплект передачи проекта

Собран 4 ноября 2026 года. В этой папке находятся проект сайта, снимок рабочей базы, материалы диагностики и инструкции для следующего агента.

**Агенту сначала прочитать `HANDOFF_AGENT.md`, затем `CURRENT_STATE.json`.**

## Содержимое

- `HANDOFF_AGENT.md` — задача, принятые решения, архитектура, ограничения и следующий этап.
- `CURRENT_STATE.json` — состояние базы на момент упаковки: публикации, очередь, источники, учётные записи без паролей.
- `SCHEDULER_STATE.json` — состояние существующего задания Windows; справочная информация, не установщик.
- `VALIDATION.txt` — результаты проверок именно упакованной копии проекта.
- `MANIFEST.sha256` — контрольные суммы файлов комплекта, кроме самого манифеста.
- `ai_portal/` — исходный проект с базой `db.sqlite3`, миграциями, шаблонами, стилями и скриптами.
- `ai_portal/README.md` — исходная инструкция разработчика.
- `ai_portal/NEWS_EDITOR_GUIDE.md` — инструкция редактора; сведения о первых 16 черновиках в ней исторические, актуальные числа см. в `CURRENT_STATE.json`.
- `ai_portal/requirements-lock.txt` — снимок всех установленных Python-зависимостей.
- `ai_portal/logs/` — журналы и `editor-review.png`, скриншот страницы проверки новости.
- `ai_portal/.source-cache/` — сохранённые ответы официальных сайтов при исследовании источников; это исторические данные, не актуальная лента.
- `ai_portal/backups/` — историческая резервная копия базы до добавления сборщика.

## Запуск копии

Распакуйте архив и откройте терминал **внутри вложенной папки `ai_portal`**. Используйте Python 3.10 или совместимый более новый Python. Проверки выполнены на Python 3.10.7.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8002 --noreload
```

Затем откройте http://127.0.0.1:8002/ или http://127.0.0.1:8002/admin/.
Если порт уже занят работающим оригиналом сайта, выберите свободный порт, например 8003, и используйте его в адресе браузера. Не останавливайте чужие проекты.

База уже заполнена: **повторно запускать `seed_demo` и `prepare_initial_drafts.py` для восстановления не нужно**. Существующий редактор — `fralmap`, пароль в комплект не записан. Пользователь вводит его сам. Сброс на нужной копии базы: `python manage.py changepassword fralmap` из её папки с активированным окружением.

Сайт запускается в режиме локальной разработки. Интернет-развёртывание ещё не выполнено.

## Что не включено и что изменено в копии

- `.venv`, Python bytecode, lock-файл сборщика и служебные файлы SQLite не переносились. Окружение восстанавливается из зависимостей.
- Активные Django-сессии удалены только из архивных копий баз: потребуется повторный вход. Рабочая база оригинала не изменена.
- Включены аккаунт редактора, хеш пароля, контактные данные в базе и редакционные журналы. Это частный комплект для передачи доверенному агенту, а не архив для публичного репозитория.
- Системное задание Windows и работающий процесс сервера не переносятся вместе с папкой. Не включайте второй сборщик без согласования основного места работы.
- Полная переписка чата не экспортирована; решения и существенные факты собраны в `HANDOFF_AGENT.md`.

Рабочий исходник остаётся по адресу `D:\gpt\ai_portal`; упаковка его не заменяет.
