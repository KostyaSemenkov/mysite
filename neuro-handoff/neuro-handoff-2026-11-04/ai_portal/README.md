# НЕЙРО — портал об искусственном интеллекте

Первая версия на Python 3.10+ и Django 5.2. Новости, статьи, каталог курсов, фильтры, поиск, пагинация, карта сайта и административная панель. Демонстрационные материалы явно помечены. Запись на демонстрационные курсы отключена.

## Запуск в Windows PowerShell

```powershell
cd D:\gpt\ai_portal
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py seed_demo
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8002
```

Сайт: http://127.0.0.1:8002/ . Остановка: Ctrl+C. Команда seed_demo повторно не создаёт дубликаты и не перезаписывает существующие записи.

## Редакция

Создайте свою учётную запись (пароль вводится интерактивно):

```powershell
.\.venv\Scripts\python.exe manage.py createsuperuser
```

Откройте http://127.0.0.1:8002/admin/ . Можно добавлять и редактировать новости, статьи и курсы, менять публикацию и главную новость. Публикации с будущей датой и черновики скрыты. Текст хранится как обычный текст с абзацами, HTML экранируется. Обложки задаются URL, без загрузки файлов в этой версии. Поиск выполняется отдельно в новостях, статьях и курсах. В SQLite регистронезависимость кириллического поиска обеспечена приложением.

## Перед публичным запуском

- Заменить демонстрационные записи реальным контентом и проверенными ссылками. Снять отметку «демонстрационный» только у реальных записей.
- Добавить контакт редакции в templates/about.html, согласовать название проекта.
- Задать DJANGO_DEBUG=0, случайный DJANGO_SECRET_KEY и DJANGO_ALLOWED_HOSTS с доменом сайта.
- Развернуть через production WSGI-сервер и HTTPS, настроить выдачу staticfiles после collectstatic. Встроенный runserver предназначен только для разработки.
- Для PostgreSQL установить psycopg и заменить DATABASES в config/settings.py на django.db.backends.postgresql с параметрами подключения из переменных окружения. Существующие данные перенести через dumpdata/loaddata с предварительной резервной копией.
- Настроить резервные копии базы, журнал ошибок и выбранную аналитику. Они не подключены к локальной версии.

Личных кабинетов читателей, платежей и хранения уроков в первой версии нет. Каталог предназначен для перехода на сайт организатора курса. Публикация в интернете требует выбранного сервера и домена.
