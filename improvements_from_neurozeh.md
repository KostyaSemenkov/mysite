# Что взять с neurozeh.ru для lemurqa.ru

Разбор сайта «Нейроцех» (neurozeh.ru — подписочный клуб по нейросетям,
лендинг собран на Claude Code) и список улучшений для «Лемурзильни тестировщика».
Порядок — по ценности для личного бренда тестировщика.

## Упаковка и конверсия

1. **Блок-«клуб» с двумя ядрами на главной.** У Нейроцеха главная сразу
   объясняет: «база знаний + комьюнити». У нас те же два ядра уже есть
   (блог/выступления + форум), но главная про это не рассказывает.
   → Переупаковать hero-секцию: «Пишу о тестировании + обсуждаем на форуме».
   Сложность: час вёрстки.

2. **Социальное доказательство цифрами.** «400 практиков, 5–6 лекций в месяц,
   47 отзывов» — цифры вызывают доверие мгновенно.
   → Счётчики на главной: количество постов, выступлений, участников форума,
   решённых тем. Считаются автоматически из базы — модели уже есть.
   Сложность: час.

3. **Сетка отзывов с кнопкой «Показать все».** Большая стена отзывов, часть
   скрыта, разворачивается по клику.
   → Модель `Testimonial` (имя, текст, фото/логотип, ссылка) + админка + сетка
   на главной или отдельной странице. Отзывы коллег/клиентов — топ-доказательство
   экспертизы QA.
   Сложность: 2–3 часа.

4. **Попапы «Читать полностью» для кейсов.** Короткая цитата в карточке,
   полная история — в модальном окне без перезагрузки.
   → Делать в связке с отзывами/кейсами: `Testimonial.full_text` + модалка
   на чистом `<dialog>` (без JS-библиотек).
   Сложность: +1 час к п.3.

5. **FAQ-аккордеон.** Вопросы про подписку, оплату, возврат — в раскрывающихся
   блоках.
   → Модель `FaqItem` (вопрос, ответ, порядок) + аккордеон на `<details>`
   (ноль JS). Идеально для будущей страницы услуг: «Как проходит аудит»,
   «Что нужно от вас», «Сколько стоит».
   Сложность: 1–2 часа.

6. **Лист ожидания (waiting list).** «Продажи открываются 26 октября» + форма
   email-уведомления. Создаёт ажиотаж и собирает базу до запуска.
   → У нас уже есть `Subscriber`! Добавить страницу-заглушку будущего продукта
   (например, «Курс по автотестам — скоро») с формой подписки.
   Сложность: 1 час.

7. **Блок «Как это работает» в 4 шага.** Визуальная лестница от действия
   к результату.
   → Для страницы услуг: «Оставили заявку → созвонились → я тестирую →
   отчёт с приоритетами». Статичная вёрстка.
   Сложность: час.

8. **Сегменты аудитории.** «Разработчикам, продактам, маркетологам» — читатель
   сразу находит себя.
   → Секция «Кому тут полезно»: джунам-тестировщикам, лидам QA, разработчикам,
   продактам — с короткими строками-пояснениями.
   Сложность: час вёрстки.

## Функции

9. **Поиск по сайту в шапке.** У Нейроцеха — прямо в меню.
   → Django `SearchVector` по постам, проектам, выступлениям и темам форума.
   Одна вьюха + страница результатов.
   Сложность: 2–3 часа.

10. **Вход через Telegram.** Авторизация не только по почте, но и одной
    кнопкой через TG — для российского IT-сайта это самый удобный путь.
    → Для форума: пакет `django-allauth` + Telegram-провайдер (нужен свой бот
    через BotFather). Гостевая премодерация остаётся как есть.
    Сложность: 3–4 часа с отладкой бота.

11. **Расписание вебинаров + архив записей.** Карточки эфиров: дата, время,
    спикер, регистрация; прошедшие — с записью.
    → Расширить модель `Talk`: статус (анонс/прошёл), дата и время эфира,
    ссылка регистрации (для будущих), видео (для прошедших) — оно уже есть!
    Выступления превращаются в «афишу + архив».
    Сложность: 2 часа.

12. **Telegram-бот с дайджестами.** У Нейроцеха бот присылает дневные дайджесты
    чата — люди возвращаются без захода на сайт.
    → Аналог для нас: бот, который шлёт вам уведомления о заявках и комментариях
    на премодерации, а подписчикам — дайджест новых постов раз в неделю.
    Сложность: 3–4 часа.

13. **Email-уведомления подписчикам.** Форма подписки есть, писем нет.
    → Простейшая отправка письма при новом посте подписчикам
    (`django.core.mail` + SMTP Mail.ru/Yandex) либо кнопка «поделиться в TG»
    как быстрый компромисс.
    Сложность: 2 часа.

## Доверие и юридика

14. **Оферта и политика конфиденциальности.** У Нейроцеха — полноценные
    юрдокументы. Для .ru-домена с формами сбора данных (у нас собираем email,
    имена, сообщения) это не опция, а гигиена; при запуске платных услуг —
    обязательство (152-ФЗ).
    → Две статические страницы + ссылки в подвал. Тексты — по шаблонам
    с заполнением ваших реквизитов, перед публикацией показать юристу.
    Сложность: 1 час (вёрстка) + тексты.

15. **Блок основателя с личной историей.** У Нейроцеха — фото Паши с ироничной
    подачей («типа настоящий предприниматель»). Работает на человекность бренда.
    → У нас есть «Обо мне», но можно вынести кусок на главную: фото + 3 факта
    + «меру упитанности» как фишку бренда.
    Сложность: час.

16. **Дублирование CTA.** Кнопки призыва («Вступить», «Что внутри») повторяются
    после каждого смыслового блока — читатель в любой точке страницы в одном
    клике от целевого действия.
    → В шаблоне главной после каждого раздела — пара кнопок
    «Связаться» / «Читать блог».
    Сложность: 30 минут.

## Мелкие штрихи

17. **Теги на карточках курсов.** Мелкие чипы технологий (Flux, Midjourney).
    → У постов и проектов теги уже есть — вынести их на карточки в списке
    проектов (сейчас только строка стека).
    Сложность: 30 минут.

18. **Партнёрские бонусы.** Сетка «подарков» от сервисов-партнёров.
    → Дальний прицел: когда появится аудитория — промокоды сервисов
    для тестировщиков (TestOps, Bugsee и т.п.) как «бонусы подписчикам».
    Сложность: когда-нибудь потом.
